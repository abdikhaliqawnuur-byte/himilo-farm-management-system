# Himilo Mixed Farm Management System

## Overview
The **Himilo Mixed Farm Management System** is a robust web-based management information system designed to streamline and automate day-to-day operations for mixed agricultural and livestock farms. Developed as an undergraduate final-year project at Puntland State University, the system replaces traditional paper-based recordkeeping with dynamic digital logging, inventory control, and real-time administrative reporting.

## Core Features & Modules
* **Secure Admin Authentication (Login Only):** Controlled system access where administrator credentials are pre-configured directly via the MySQL database, ensuring secure backend operations without public sign-up.
* **Livestock & Health Tracking:** Tracks animal inventory, medical/vaccination records, breeding history, and yield outputs.
* **Crop & Yield Management:** Monitors planting timelines, fertilizer logs, field management, and harvest yields.
* **Inventory & Stock Control:** Tracks farm feed, machinery maintenance, medical supplies, and fertilizers.
* **Financial Reporting & Analytics:** Generates dynamic income, sales, and expense summaries.

## Technical Architecture & Database Design
* **Backend:** PHP (Object-Oriented Programming & Logic)
* **Database:** MySQL (Relational Database Schema with Normalized Tables)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Security:** Secure session management, password hashing, and restricted direct URL access.
